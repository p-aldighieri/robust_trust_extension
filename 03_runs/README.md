# Raw Runs

This directory contains raw proof-run workspaces: prompt packets, response logs,
role contexts, scripts, and run-specific source notes. Treat these as
provenance, not polished exposition.

## Run Groups

- `menu_engine_202605/`: May 2026 menu-engine run that produced the v8 terminal
  state and the post-v8 route audit.
- `context_management_202603/`: March 2026 context-management and earlier route
  exploration workspace.
- `theorem_alternative_proof/`: earlier alternative-proof/minimax route
  workspace, including rendered local proof notes.
- `proof_attempt_archivara_pass1/`: archived first pass proof attempt.

Generated LaTeX files and local scratch outputs are intentionally ignored by
the repository-level `.gitignore`.
