On the current banked record, the right ranking is:

1. **Finite-palette lemma**
2. **Tail-stability / closedness lemma**
3. **Monotone-refinement / eventual-constancy lemma** 

The **finite-palette lemma** should be tried first. It is the most direct response to the exact obstruction that is now trusted: the current record gives only coordinatewise nonemptiness of the witness sets (K_j), but not the extraction of an infinite subset carrying one common compatible witness class. The reviewer-cleared diagnosis says the first failure is precisely the missing step from infinitely many unmoved coordinates to one compatible local witness family, and the prover note isolates the bad pattern as the injective incompatibility configuration (K_j={\kappa_j}) with pairwise incompatible (\kappa_j). A finite-palette statement is exactly the minimal kind of cross-coordinate structure that kills that pattern. Once there are only finitely many compatibility classes, countable infinitude of (U) immediately gives an infinite compatible subfamily by pigeonhole, with no appeal to approximation or downstream tail assembly. So this route is closest to the exact gap and has the cleanest local win condition.  

The **tail-stability / closedness lemma** should wait, but it is the best backup. The reason is that the current record already warns that compactness by itself is too weak: a convergent subsequence of rays need not contain an infinite constant fiber, and it need not yield one exact cone/ray that remains locally admissible for infinitely many coordinates. So this path only becomes live if one can prove a genuinely stronger statement converting approximate common direction into exact common admissibility on an infinite tail. That means this route carries extra burdens not yet banked. **Needed assumption:** a normalized witness space with enough sequential compactness to extract limits. **Needed assumption:** a closedness theorem saying local admissibility/compatibility is preserved under those limits across a tail. Since neither ingredient is currently in hand, this route is more indirect than the finite-palette attack and should be second, not first. 

The **monotone-refinement / eventual-constancy lemma** should be last. It would certainly be powerful enough if true, but on the present record it is the least motivated shape. The prover note explicitly says there is no banked monotonicity or nesting principle on ((K_j)_{j\in U}), and the reviewer-cleared diagnosis likewise treats monotonicity as one possible new lemma, not as something already hinted by the existing structure. So this route asks for the strongest new cross-coordinate architecture while solving a problem that, at least locally, only needs finite classification. **Needed assumption:** a compatibility preorder under which the witness sets are nested, refining, or eventually constant along the tail. Nothing in the current banked record points to that order-theoretic structure, so it should wait until the simpler finite-classification attempt has been tried and either proved or cleanly failed. 

This ranking also fits the durable state of the project. The current best trusted theorem is still the finite-(M), compact-metric-(\Theta) result, and the atomic branch is being used to attack the first sharp obstruction to removing finiteness of (M). So the best next move is the narrowest U-side lemma that directly targets the now-cleared non-derivability point, rather than importing heavier limit or monotonicity machinery too early. 

Suggested next local action: formalize the witness-set map (j \mapsto K_j), define the compatibility relation precisely, and try to prove a finite-palette lemma stating that the banked local witness classes on (U) fall into finitely many compatibility classes, so that an infinite compatible subfamily follows immediately by pigeonhole.
