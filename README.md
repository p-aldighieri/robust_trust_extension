# robust_trust_extension

This repository is for extending a proof from:

- Piotr Dworczak and Alex Smolin, *Robust Trust* (2026)
- arXiv: https://arxiv.org/abs/2602.09490
- Local copy: `Robust_trust_Dworczak_Smolin.pdf`

The current objective (see `objective_statement.md`) is to develop an extension of the paper's proof framework, with a focus on generalizing the Theorem 2 argument beyond the finite-setting assumptions.

In future updates, this repo will contain the extension itself, full proofs, supporting lemmas, and related technical notes.
